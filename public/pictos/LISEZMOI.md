# Pictogrammes ARASAAC

Ce dossier reçoit les images téléchargées par `npm run pictogrammes`.

Elles ne sont pas versionnées ici par défaut : chaque publication du site les
récupère automatiquement depuis ARASAAC. Pour un usage hors connexion, lancez
le script puis ajoutez les fichiers obtenus au dépôt.

Pictogrammes : Sergio Palao pour ARASAAC (<https://arasaac.org>), propriété du
Gouvernement d’Aragon, sous licence CC BY-NC-SA.
